# Karachi AQI Forecast

An end-to-end serverless machine learning system for forecasting the Air Quality Index in Karachi for the next three days.

## Project Objectives

- Collect live weather and air pollution data
- Build historical and real-time feature pipelines
- Store model features in a feature store
- Train and compare machine learning forecasting models
- Automate data collection and model retraining
- Serve predictions through a Flask API
- Display forecasts through an interactive Streamlit dashboard
- Explain predictions using SHAP

## Technology Stack

- Python
- Scikit-learn
- TensorFlow
- Hopsworks
- GitHub Actions
- Flask
- Streamlit
- SHAP
- Git and GitHub
